# Quizymode Mobile User Guide

**App:** [www.quizymode.com](https://www.quizymode.com)

This guide mirrors the main signed-in Quizymode walkthrough on a phone-sized screen, highlighting mobile navigation, stacked layouts, and full-screen overlays.
_Screenshots are captured from the live site and published to [GitHub Pages](https://yanis-kr.github.io/Quizymode/) by the Publish User Guide workflow. The images here show the latest published guide, which may differ from this repo version._

## Home

### Home

On mobile, the five-question quick quiz remains the primary home action and states that no account is needed. It starts a mixed five-question quiz directly, while the category carousel stays immediately below it for browsing. The primary navigation moves behind the hamburger menu and the hero content wraps for a narrow screen.

![Home](https://yanis-kr.github.io/Quizymode/assets/mobile/01.home.png "Home")

## Featured

### Featured

On mobile, the **Featured** page keeps the same Sets / Collections tab switcher and Sort control, but both controls and the card grid stack into a single-column layout. Each card fills the full screen width, making the category path, item count, and last-modified date easy to read at a glance without horizontal scrolling.

![Featured](https://yanis-kr.github.io/Quizymode/assets/mobile/02.featured.png "Featured")

## Browsing the Taxonomy

### Categories

The Categories page keeps the same search and sort tools on mobile, but the controls stack vertically and the results fill the screen one card at a time. This makes category browsing feel more like a feed, with each tap moving deeper into the taxonomy.

![Categories](https://yanis-kr.github.io/Quizymode/assets/mobile/03.categories.png "Categories")

### Nav Geography

On mobile, opening Geography keeps the breadcrumb trail but the topic cards stack and wrap to fit the narrow screen. The focus shifts to one tap target at a time, which makes drilling into the taxonomy easier with a thumb.

![Nav Geography](https://yanis-kr.github.io/Quizymode/assets/mobile/04.nav-geography.png "Nav Geography")

### Nav Geography Capitals

At the subtopic level, mobile keeps the same hierarchy but presents the choices in a tighter stacked grid. You still navigate by tapping a subtopic card, but the layout is optimized for narrow-width browsing.

![Nav Geography Capitals](https://yanis-kr.github.io/Quizymode/assets/mobile/05.nav-geography-capitals.png "Nav Geography Capitals")

### Nav Geography Capitals World

At the leaf level, the item view switches into the same **List** mode as desktop, but the mode controls and action buttons may wrap across multiple lines. The narrow layout keeps the question content readable while still exposing the study-mode switcher.

![Nav Geography Capitals World](https://yanis-kr.github.io/Quizymode/assets/mobile/06.nav-geography-capitals-world.png "Nav Geography Capitals World")

### Mode Flashcards

On mobile, flashcards stay focused on one item at a time, with the card taking most of the viewport. Navigation controls sit close to the card so you can flip and advance without leaving the screen.

![Mode Flashcards](https://yanis-kr.github.io/Quizymode/assets/mobile/07.mode-flashcards.png "Mode Flashcards")

### Mode Quiz

Quiz mode on mobile keeps the same multiple-choice flow, with the question, answers, and progress stacked vertically for easier thumb interaction. The first answer remains locked, and the completion screen provides touch-friendly mistake review and replay actions.

![Mode Quiz](https://yanis-kr.github.io/Quizymode/assets/mobile/08.mode-quiz.png "Mode Quiz")

## Building Your Collection

### Items Add To Collection

Collection controls remain available in mobile study views, but they compress beneath or alongside the content depending on space. The goal is the same one-tap add flow, with the controls adapted to a tighter card layout.

![Items Add To Collection](https://yanis-kr.github.io/Quizymode/assets/mobile/09.items-add-to-collection.png "Items Add To Collection")

### Items Collection Badges

After you add items on mobile, the filled collection badges remain visible directly on the compact item cards. This makes it clear which items are already in the active collection without needing extra panels.

![Items Collection Badges](https://yanis-kr.github.io/Quizymode/assets/mobile/10.items-collection-badges.png "Items Collection Badges")

### Items Collection Removed

Removing an item from the active collection works the same on mobile. The item card updates in place, freeing the add button again and keeping the workflow quick on a narrow screen.

![Items Collection Removed](https://yanis-kr.github.io/Quizymode/assets/mobile/11.items-collection-removed.png "Items Collection Removed")

### Active Collection Selector

The active collection workflow is still available on mobile, but the management dialog becomes more sheet-like and space-efficient. You can create or switch collections without leaving the current study context.

![Active Collection Selector](https://yanis-kr.github.io/Quizymode/assets/mobile/12.active-collection-selector.png "Active Collection Selector")

### Collection New

Creating a new collection on mobile uses the same form fields, but the modal stacks vertically and fills more of the screen. This keeps the create flow readable without relying on a wide dialog.

![Collection New](https://yanis-kr.github.io/Quizymode/assets/mobile/13.collection-new.png "Collection New")

### Collections Mine Two

With multiple collections on mobile, the **My Collections** view turns into a vertical stack of cards. Actions remain on each card, but the layout favors readable summaries over wide side-by-side tiles.

![Collections Mine Two](https://yanis-kr.github.io/Quizymode/assets/mobile/14.collections-mine-two.png "Collections Mine Two")

### Keyword Filter

Keyword filtering still works with one tap on mobile, though the tag row may wrap into multiple lines. That compressed layout helps keep filtering available even in narrow list views.

![Keyword Filter](https://yanis-kr.github.io/Quizymode/assets/mobile/15.keyword-filter.png "Keyword Filter")

### Item Detail

The item detail page on mobile shows the same information as desktop, but the sections stack into a single-column reading flow. This makes long answer, explanation, and metadata blocks easier to scan vertically.

![Item Detail](https://yanis-kr.github.io/Quizymode/assets/mobile/16.item-detail.png "Item Detail")

### Item Rating Five Stars

Rating on mobile keeps the same immediate-save behavior, but the stars are placed in a tighter row within the stacked item detail layout. The interaction remains quick and touch-friendly.

![Item Rating Five Stars](https://yanis-kr.github.io/Quizymode/assets/mobile/17.item-rating-five-stars.png "Item Rating Five Stars")

### Item Comment Added

On mobile, the comments experience opens as a full-screen overlay rather than a side drawer. You can read and post comments without navigating away, while still keeping the focus entirely on the discussion thread.

![Item Comment Added](https://yanis-kr.github.io/Quizymode/assets/mobile/18.item-comment-added.png "Item Comment Added")

## Collections

### Collections Mine

The **My Collections** tab uses the same data on mobile, but each collection becomes a full-width card in a vertical list. This makes the page easier to browse without shrinking controls or metadata too aggressively.

![Collections Mine](https://yanis-kr.github.io/Quizymode/assets/mobile/19.collections-mine.png "Collections Mine")

### Collection Detail

A collection's study page keeps the same modes on mobile, but the controls wrap and the content flows vertically. The screen is optimized for reading and swiping through one collection at a time.

![Collection Detail](https://yanis-kr.github.io/Quizymode/assets/mobile/20.collection-detail.png "Collection Detail")

### Collection Detail Flashcards

Collection flashcards on mobile keep the answer-first card interaction, but the card and navigation controls dominate the viewport. This makes the study session feel more like a dedicated handheld practice mode.

![Collection Detail Flashcards](https://yanis-kr.github.io/Quizymode/assets/mobile/21.collection-detail-flashcards.png "Collection Detail Flashcards")

### Collection Detail Quiz

Collection quiz mode keeps first-answer scoring and completion review on mobile, with content stacked for touch interaction. Results offer mistake review, return, and same-roster replay without leaving the collection flow.

![Collection Detail Quiz](https://yanis-kr.github.io/Quizymode/assets/mobile/22.collection-detail-quiz.png "Collection Detail Quiz")

### Collection Settings Public

Collection settings on mobile use the same fields and sharing toggle, but the edit dialog is more vertically arranged. That keeps the sharing workflow usable without a desktop-width modal.

![Collection Settings Public](https://yanis-kr.github.io/Quizymode/assets/mobile/23.collection-settings-public.png "Collection Settings Public")

### Collections Discover Public

Discover still shows newly public collections on mobile, but the browse experience becomes a vertical stream of cards. Search and filtering stay available while the card layout remains easy to read on small screens.

![Collections Discover Public](https://yanis-kr.github.io/Quizymode/assets/mobile/24.collections-discover-public.png "Collections Discover Public")

### Collection Bookmark

Bookmarking a public collection works the same on mobile with a single tap, and the card updates in place. The interaction stays lightweight even in the compact Discover layout.

![Collection Bookmark](https://yanis-kr.github.io/Quizymode/assets/mobile/25.collection-bookmark.png "Collection Bookmark")

### Collections Bookmarked

Bookmarked collections are shown as a mobile-friendly stacked list. You can open or remove bookmarks directly from the narrow card layout.

![Collections Bookmarked](https://yanis-kr.github.io/Quizymode/assets/mobile/26.collections-bookmarked.png "Collections Bookmarked")

## Adding Items

### Add Items

The Add Items hub keeps the same branching workflow on mobile, but the scope controls, notices, and action buttons stack into a single-column layout. This makes the create options easier to scan on a phone.

![Add Items](https://yanis-kr.github.io/Quizymode/assets/mobile/27.add-items.png "Add Items")

### Add Items Prepopulated

When Add Items opens from a scoped category on mobile, the same category and keyword selections are pre-filled. The difference is mostly layout: the scope controls and compliance notice stack for narrow screens.

![Add Items Prepopulated](https://yanis-kr.github.io/Quizymode/assets/mobile/28.add-items-prepopulated.png "Add Items Prepopulated")

### Add New Item

The Create Item form becomes a long, single-column form on mobile, with fields and actions stacked top to bottom. This keeps every required input accessible without shrinking the form controls.

![Add New Item](https://yanis-kr.github.io/Quizymode/assets/mobile/29.add-new-item.png "Add New Item")
